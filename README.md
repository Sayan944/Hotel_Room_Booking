# Hotel Room Booking System 

## Project Overview : The Hotel Room Booking System is a full-stack web application designed to automate hotel operations. The system provides separate dashboards and functionalities for different types of users (system admin, registered guests, and front-desk staffs), ensuring secure access and efficient management of hotel services.

The application follows a client-server architecture where the frontend communicates with the backend APIs and stores data in a MySQL database.

# User Roles

The system consists of three different panels:

# 1. Guest/User Panel
Guests can:
- Register and Login
- Browse available rooms and search by applying filters
- Book rooms
- View booking history
- Cancel bookings
- Check booking status
- Submit ratings and reviews
- Request for Services

# 2. Front Desk Panel
Front Desk staff can:
- Check-in guests
- Check-out guests
- Manage reservations
- Search guest records
- Assign Housekeeping Staff
- Generate bills

# 3. System Admin Panel
The System Admin manages and checks the daily hotel operations. Features include:
- Dashboard
- Guest Management
- Room Management
- Booking Management
- Housekeeping Management
- Revenue Monitoring
- Feedback Management
- Staff Management
- View Reviews

This project follows a client-server architecture:
- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** MySQL

# Database Setup

1. Install MySQL.
2. Create the required database. (Example: CREATE DATABASE hotel_management;)
3. Import the SQL file (provided). (mysql -u root -p < database.sql)
4. to Update the database credentials inside: backend/.env or backend/db.js

# Installation

# 1. Extract the ZIP
Extract the project anywhere.

# 2. Backend Setup
Navigate to the `backend` directory: cd backend
(install backend packages if required) : npm install
npm start : *Backend server will start at `http://localhost:5000`* or any other port specified in the cmd terminal

# 3. Frontend Setup
Navigate to the `frontend` directory: cd frontend
(Install the required frontend packages, if not already) : npm install  
npm run dev : *Frontend application will start at `http://localhost:5173`* or any other port specified in the cmd terminal

# Troubleshooting Operations :-

# 1. Port Already in Use
Change the port number in : backend/.env or server.js

# 2. Database Connection Error
Check:
- MySQL service is running
- Database exists
- Username/password are correct
- Port number is correct

# 3. npm command not found
- Install Node.js and restart the terminal.
- Verify:
    node -v
    npm -v

# 4. Module Not Found
Run: npm install inside both backend and frontend
